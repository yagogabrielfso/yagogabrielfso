### Oi, sou o Yago

Ultimamente tenho estudado mensageria com Kafka, performance e resiliência de APIs, observabilidade com OpenTelemetry e como colocar LLMs dentro de aplicações .NET de um jeito que dê para manter.

**Stack do dia a dia:** C#, ASP.NET Core, EF Core, SQL Server, PostgreSQL, Docker, Kubernetes, Azure DevOps
